## How it works

`main.py` holds the coined one-word entry as a constant, asserts it is non-blank, single-line, contains no whitespace, and is 1-30 characters long, then writes it as UTF-8 bytes with no trailing newline to `/output/entry.txt`, creating the output directory if needed.

## Run

```bash
python3 main.py
cat /output/entry.txt
```
